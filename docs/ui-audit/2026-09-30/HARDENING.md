## 再現

Playwright導入済み環境で、必要に応じてパッケージの場所を指定します。製品の実行にNode.jsやPlaywrightは不要です。

```powershell
$env:STRATA_AUDIT_PLAYWRIGHT = 'Playwright パッケージの絶対パス'
rtk proxy node --test web/app_channel_options.test.cjs web/hardening.browser.test.cjs
rtk proxy "C:\Program Files\Go\bin\go.exe" test ./internal/wui
```

`STRATA_AUDIT_OUTPUT` に一時出力先を指定すると、測定JSONと画面画像を保存します。Web資産をlocalhostへ配信し、APIは架空番組・sample config・テスト応答に固定します。本番DBや設定への書き込みはありません。
